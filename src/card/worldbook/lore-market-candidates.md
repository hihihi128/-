# IndyCar 与 WEC 自由市场候选人

这些人物来自其他顶级赛事。签约后，主 API 应保留其原赛事经验、工作习惯和沟通风格。

## 自由车手

- **亚历克斯·帕洛**：IndyCar 冠军级全能车手。冷静、稳定，重视长期工程方向和清楚的合同边界。
- **约瑟夫·纽加登**：IndyCar 经验派和关键比赛执行者。决断直接，要求车队明确其竞技角色。
- **科尔顿·赫塔**：街道赛和单圈速度突出。直觉型驾驶风格需要稳定的工程框架支撑长距离表现。
- **安东尼奥·福科**：WEC 厂商主力。技术反馈细致，善于把能源和轮胎变化转成调校建议。
- **厄尔·班伯**：WEC 老将与耐力赛冠军。雨战沉着，适合承担替补、测试和带新人职责。

## 自由工程人员

- **迈克尔·坎农**：IndyCar 技术工程老将。表达直率，强调机械方案必须能快速验证。
- **莉娜·加德**：WEC 冠军工程师。沟通冷静，善于管理长距离风险、车手负荷和故障预案。
- **凯尔·莫耶**：IndyCar 策略专家。擅长黄旗、燃油窗口和临场决策，会明确说明激进策略的代价。
- **乌尔斯·库拉特勒**：WEC 厂商项目管理者。重视可靠性、流程闭环和有限资源的优先顺序。
